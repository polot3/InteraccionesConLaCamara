# ⚡ Inicio Rápido en 3 Pasos

## Paso 1️⃣: Servir la Aplicación

Abre PowerShell/CMD en la carpeta del proyecto y elige UNA opción:

```powershell
# Opción 1: Python (recomendado)
python -m http.server 8000

# Opción 2: Node.js
npx http-server

# Opción 3: PHP
php -S localhost:8000
```

## Paso 2️⃣: Abrir en Navegador

Abre tu navegador y ve a:
```
http://localhost:8000
```

## Paso 3️⃣: Permitir Cámara y ¡Jugar!

1. Haz clic en **"Iniciar Cámara"**
2. Permite el acceso cuando el navegador lo solicite
3. **¡Levanta tus manos hacia la cámara!** 🖐️
